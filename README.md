# Scam Sathi By C Vc

Build a beautiful, modern, responsive web application called ScamSathi AI — Your Personal Digital Safety Assistant.

The goal is to help people identify potential online scams in suspicious messages, fake job offers, prize notifications, phishing attempts, and payment requests.

DESIGN:

Professional cybersecurity-inspired design.

Dark navy, white, and teal color palette.

Clean, modern cards with subtle shadows and rounded corners.

Mobile-first, fully responsive layout.

Easy for non-technical people to understand.

PAGES AND FEATURES:

A hero section with the headline "Think Before You Trust."

A short description explaining how ScamSathi helps people stay safe online.

A large text area where users can paste suspicious messages.

An Analyze Message button.

Example message buttons so users can try the app immediately.

A results section with a risk category, warning signs, a plain-language explanation, and recommended safety actions.

Language selection for English and Roman Urdu, with Urdu support if feasible.

A short privacy notice and disclaimer explaining that AI analysis is not guaranteed to be correct.

Loading indicators, input validation, and friendly error messages.

IMPORTANT:

Build the actual working frontend, not just a static landing page.

Make the initial interface polished and functional before adding advanced features.

Keep components organized and code maintainable.

Do not pretend an analysis is real if the AI API is not connected. Clearly label any sample output as a demo.

Do not expose API keys in frontend code.

Do not add authentication, subscriptions, or a database.

Make the app easy to connect to a secure server-side AI endpoint later.

First, generate the complete frontend and make sure the preview works. Then explain what is implemented and what remains to connect the live AI analysis.
